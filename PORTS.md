# Board ports

Every browser cart (`build.zig` cart matrix) and its KESTREL board port. Generated by
`gen_ports.py` in the board-more-carts scratchpad: rerun it after a build, don't edit by hand.

- **Shelf** — on the current SD shelf (`glass_shelf.py` `SHELF`, old format).
- **Old fw** — the monolithic `fw.bin` (feat/board-more-carts, `ZM_FPU=1 ZM_AUDIO=snd`).
- **#127 cart** — the lean cart image (feat/board-more-carts-split, over one `system.rv32`).
- **Sim** — `hp_sim_run.py --fpu --frames 60`; **Board** — tried on the board.
- **Float** — float in the cart's own code: `frame` = in the per-frame path (slow on the board: f64 is
  always soft-float, f32 is hardware only on the FPU build), `init` = only building tables, `trivial` = one dt conversion a frame, ⚠️ = f64 per frame.
  From a code audit (floats.json), not a measurement.
