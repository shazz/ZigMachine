## eas-vhs.ttf — "EAS VHS"

Used by the VHS-style cart OSD (`docs/cart-osd.js`).

- **Designer:** elliotshock, on FontStruct
- **Source:** https://fontstruct.com/fontstructions/show/2878521/eas-vhs
- **Licence:** CC0 — copyfree, no conditions. (Matt, 2026-09-20)

Note for anyone auditing this later: the TTF's own `name` table (records 13/14)
claims "Creative Commons Attribution" / CC BY 3.0, and the dafont ZIP ships no
licence file at all. The FontStruct page — the creator's own listing — says CC0,
which is authoritative over stale metadata baked into the file. Recorded here so
the discrepancy does not have to be rediscovered.
