SKYSTRIKE (cart 79), ZIG mode: the three ProTracker modules and their licences
===============================================================================

ZIG mode plays these three 4-channel ProTracker modules, one per situation
(apps/zig/scenes/skystrike/zig_music.zig). ORIGINAL mode plays skystrike.sndh,
the game's own music. Each file below is unmodified, as downloaded from
The Mod Archive (https://modarchive.org). The licence of each was read from
its own Mod Archive page.

The licences below apply to the MUSIC FILES ONLY. They do not extend to the

share-alike condition of CC BY-SA 4.0 binds only skystrike_explore_the_sky.mod
(and any modified version of that file), not the game or the code that plays it.
