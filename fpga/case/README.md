# fpga/case: the KESTREL / PEREGRINE case

Everything for the 3D-printed case of the console (VCF Montreal stand): the measurements, the
parametric OpenSCAD model, exported STLs, photos and fit notes.

- `PLAN.md`: the measurement sheet and the design approach.
- `kestrel_case.scad`: the model (every dimension a named variable from the measurements).
- `stl/`: exports, one per printed part.
- `photos/`: reference photos of the board and the hub (with a ruler).

One case for both boards: KESTREL (MicroPhase Z7-Lite 7010, `fpga/boards/microphase_z7_7010/`) and
PEREGRINE (the 7020 variant, `fpga/boards/microphase_z7_7020/`).
